## Чистый фон первого экрана
Пользователь подтвердил, что отдельного hero-image пока нет. В текущей версии используются чистые фрагменты эскиза, CSS-позиционирование и затемнение под живым текстом. Левая часть исходной фотографии закрыта надписями в макете и не может быть точно извлечена. Для точного воспроизведения нужен чистый фон не менее 1920 × 900: тихое озеро, смешанный белорусский лес поздней осенью, приглушённая охристо-зелёная палитра, лёгкий туман, женщина со спины на деревянном причале справа; слева свободное место под текст. Заменить фон можно в CSS без изменения HTML.
