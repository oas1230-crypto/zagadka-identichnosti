# Загадка идентичности

Статический лендинг психологического выездного шаттла 27–29 ноября 2026 года.

## Локальный запуск
Из этой папки: `python3 -m http.server 4173 --bind 127.0.0.1`, затем открыть http://127.0.0.1:4173.

Сборка: `npm run build`. Зависимости устанавливать не требуется. Публичные файлы копируются в `dist/`; служебные документы и исходные скриншоты в публикацию не входят.

## Изменения
- `index.html` — содержание, даты, биографии, телефон и Instagram.
- `styles.css` — оформление и адаптивность.
- `site-config.js` — персональная ссылка Telegram; пустое значение скрывает контакт.
- `assets/` — оптимизированные изображения.
- `docs/SOURCES.md` — происхождение изображений и биографических сведений.

## История
Этот каталог — отдельный Git-репозиторий. Исходные материалы сохранены рядом, вне репозитория: `../photos/originals/` и `../design/`. Сохранены оригинальные байты и проверены SHA-256 из переданного пакета.

Публикация и итоговые проверки описываются по завершении реализации.
