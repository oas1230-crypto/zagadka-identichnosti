# Загадка идентичности

Статический лендинг психологического выездного шаттла 27–29 ноября 2026 года.

## Локальный запуск
Из этой папки: `python3 -m http.server 4173 --bind 127.0.0.1`, затем открыть http://127.0.0.1:4173.

Сборка: `npm run build`. Зависимости устанавливать не требуется. Публичные файлы копируются в `dist/`; служебные документы и исходные скриншоты в публикацию не входят.

## Изменения
- `index.html` — содержание, даты, биографии, телефон и Instagram.
- `styles.css` — оформление и адаптивность.
- `assets/` — оптимизированные изображения.
- `docs/SOURCES.md` — происхождение изображений и биографических сведений.

## История
Этот каталог — отдельный Git-репозиторий. Исходные материалы сохранены рядом, вне репозитория: `../photos/originals/` и `../design/`. Сохранены оригинальные байты и проверены SHA-256 из переданного пакета.

## Публикация на бесплатном GitHub Pages
Workflow `.github/workflows/pages.yml` проверяет сайт, собирает `dist/` и публикует его после каждого push в `main`. Установка зависимостей, сервер и платные сервисы не требуются. На бесплатном плане нужен публичный репозиторий.

После подключения согласованного репозитория выбрать в GitHub **Settings → Pages → Source → GitHub Actions**. Отправить историю обычным `git push -u origin main`. Перед отправкой в существующий репозиторий выполнить `git fetch origin` и проверить историю; не использовать force push.

Для следующих обновлений: изменить файлы, выполнить `npm run build`, проверить страницу, затем `git add`, `git commit` с описанием изменения и `git push`. Статус публикации смотреть во вкладке Actions. Все ресурсы подключены относительными путями и работают под префиксом репозитория.

В Git входят только код, обработанные изображения и документация. Публичная сборка формируется по явному списку в `scripts/build.mjs`, поэтому документы и оригинальные материалы на Pages не попадают.

## Проверки и ограничения
`npm run check` проверяет ресурсы, якоря, метаданные и контакты. `npm run build` дополнительно формирует публикацию. Результаты проверки браузером — в `docs/QA.md`.

Telegram полностью удалён по указанию организатора. Сайт не содержит форм, аналитики, внешних библиотек или клиентского JavaScript. Раскрытие биографий работает штатным элементом `details`.

Для точного воспроизведения первого экрана нужен чистый фон без надписей. Текущий фон собран из доступных фрагментов утверждённого эскиза; техническое описание нужного исходника — в `docs/SOURCES.md`. Кадрирования интерьера, беседы и пейзажа имеют ограниченное разрешение.
